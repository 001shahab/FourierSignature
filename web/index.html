Every closed curve is a sum of rotating vectors: z(t) = Σ ck e2πikt. The discrete Fourier transform finds one circle per frequency; adding them tip to tail retraces your pen. Fewer circles give a smooth sketch, more circles recover every detail. Exported points can be rendered to GIF, MP4 or animated SVG with the fourier-signature command line tool.
